BOUTIQUES UTGAWA : VETEMENTS / ACCESSOIRES / BARBIER / TATOUAGE  (Crestwood RP)
=================================================================================

Systeme de creation de personnage + boutiques, integre a l'editeur "@clothes" deja present
dans l'APK (CharacterCreator / ClothesCustomization, dialogues 9550-9554). Aucun plugin.

1) CREATION DU PERSONNAGE
   Tant qu'un compte n'a pas d'apparence sauvegardee : /vetements ouvre l'editeur complet,
   tout est GRATUIT (comme avant). Le genre / modele ne se choisit qu'ici.
   Ensuite /vetements est reserve au staff : la tenue change dans les boutiques.
   (UTGS_EDITOR_LIBRE 1 = remettre l'ancien comportement.)

2) BOUTIQUES
   Creation par un admin (niveau UTGS_ADMIN_LVL = 4 mini, echelle 0-10 du panneau), a pied, a l'endroit voulu :
     /criarroupa       boutique de vetements  (haut, bas, chaussures)
     /criaracessorio   boutique d'accessoires (chapeau, lunettes, masque, boucles, collier, montre, sac)
     /criarbarbearia   barbier                (cheveux + couleur, sourcils, barbe, maquillage)
     /criartatuagem    salon de tatouage      (bras G/D, jambes G/D, dos, torse)
     /deletarloja      supprime la boutique la plus proche (4 m)
     /lojas            liste    |   /irloja <id>  teleporte
   Chaque boutique = pickup vetements SA-MP (1275) + texte 3D + icone sur la carte
   (icones 40..99 : 45 vetements/accessoires, 7 barbier, 39 tatouage). Sauvegardees (table utg_shops).

   Le joueur marche sur le pickup -> l'editeur s'ouvre avec "shop":1..4 dans le JSON.
   A l'enregistrement le SERVEUR :
     - remet comme avant tout ce que la boutique ne vend pas (et renvoie l'apparence au client) ;
     - fait payer chaque piece NOUVELLE (UTGS_PRIX_* , 1000 par defaut) en argent liquide ;
     - une piece deja achetee se remet gratuitement (table utg_owned) ; retirer une piece = gratuit ;
     - refuse si pas assez d'argent (le client revient a la tenue enregistree).
   Un policier en uniforme doit d'abord remettre sa tenue civile au vestiaire.

7) MODELES DFF / TXD DANS LE MODPACK
   Les corps du pack UTGAWA (male.dff / female.dff) ont les memes materiaux que ceux que l'APK habille deja
   (fantasy_m_* / fantasy_f_* / body.*), et le catalogue de l'APK (ClothesAvz.h) a les memes pieces.
     male.dff + male.txd     -> skin 7   (male01)  dans l'img du modpack   = "Homme 3" de la creation
     female.dff + female.txd -> skin 12  (bfyri)   dans l'img du modpack   = "Femme 2" de la creation
   Les vetements sont des TEXTURES posees sur ces corps. L'APK les cherche dans la texdb du jeu sous les noms
     brl_m7_clothes_<materiau>_<NN>  (homme)   brl_f9_clothes_<materiau>_<NN>  (femme)
   (ex. brl_m7_clothes_fantasy_m_torso2_08 = haut style 2, variante 8 ; texture absente = piece masquee).
   Les TXD cs7_* / cs9_* du pack ont a priori les memes images (memes nombres de variantes par piece) sous d'autres
   noms (ex. cs7_tshirts : 2_8). Si ta texdb a deja les brl_..., rien a faire ; sinon
   pour ajouter / remplacer un vetement, il faut l'ajouter a la texdb sous le nom brl_... attendu.
   Les interieurs (bshop01, intra_odejda, intra_akses + .col) sont optionnels : il faut leur donner un id
   d'objet libre (IDE + img du modpack) pour les poser avec CreateObject.
