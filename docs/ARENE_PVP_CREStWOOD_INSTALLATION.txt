CRESTWOOD RP - ARENE PVP (version initiale serveur)
===================================================

COMMANDES
/arenacreate : administrateur niveau 1 minimum; crée l'arène à la position et à l'orientation de l'admin.
/arenajoin   : rejoint l'arène si elle a déjà été créée par un administrateur.
/arenaleave  : quitte l'arène.
/arenastats  : affiche les éliminations, morts et victoires sauvegardées.

PERSISTANCE
Le gamemode utilise le SQLite intégré de SA-MP. Au démarrage, il crée automatiquement
scriptfiles/crestwood_arena.db, avec les tables arena_config et arena_stats. Aucun plugin
MySQL n'est requis. Les stats sont sauvegardées après chaque élimination/mort, à la sortie
de l'arène et à la déconnexion.

SQL (SQLite)
CREATE TABLE IF NOT EXISTS arena_config (
  id INTEGER PRIMARY KEY CHECK (id = 1),
  x REAL NOT NULL, y REAL NOT NULL, z REAL NOT NULL, angle REAL NOT NULL
);
CREATE TABLE IF NOT EXISTS arena_stats (
  name TEXT PRIMARY KEY COLLATE NOCASE,
  kills INTEGER NOT NULL DEFAULT 0,
  deaths INTEGER NOT NULL DEFAULT 0,
  wins INTEGER NOT NULL DEFAULT 0
);

Le gamemode exécute déjà ces CREATE TABLE IF NOT EXISTS automatiquement.
Si tu veux les exécuter manuellement, utilise SQLite sur le fichier
server/basicgm/scriptfiles/crestwood_arena.db (ou le dossier scriptfiles de ton serveur).

LIMITES À CONNAÎTRE
- Cette première intégration ajoute le système serveur et un pickup/texte 3D SA-MP standard.
- Le symbole de main personnalisé de la référence Reduto n'est PAS encore intégré au rendu natif
  Android; cela exige une modification du moteur de rendu client (32 et 64 bits) et un modèle/
  une texture adaptés. Ne pas présenter le pickup standard comme la main Reduto.
- L'arène utilise un monde virtuel dédié (777). Il s'agit d'une première base fonctionnelle, pas
  encore d'une arène complète avec matchmaking, manches, classement HTML ou zone de combat.
- La compilation Pawn et les tests en jeu doivent être effectués avant déploiement en production.
