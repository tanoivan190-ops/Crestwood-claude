CRESTWOOD RP - MAPPINGS, STREAMING, SYSTEMES MTA CONVERTIS (30/10/2026)
=======================================================================

1) POURQUOI "LES TRUCS DISPARAISSENT" (bug visuel) - 2 causes trouvees et corrigees
-----------------------------------------------------------------------------------
 a) Client 32 bits : la memoire de streaming du moteur restait a 50 Mo (15 Mo sur les
    telephones detectes "faibles"). Notre reglage ecrivait dans une ancienne variable que le jeu
    ne lit plus. Resultat : le jeu jetait les modeles des qu'il y avait trop d'objets -> les
    batiments / mappings clignotent ou disparaissent. C'est pour ca que "sur d'autres telephones
    ca passe" (plus de RAM / pas en mode faible).
    Correction (32 ET 64 bits, game/Streaming.cpp + game/hooks.cpp) : budget = 1/4 de la RAM du
    telephone, entre 160 Mo et 512 Mo, applique au demarrage ET a chaque demande de place.
 b) Serveur : SA-MP n'affiche que 1000 objets maximum par joueur. Le streamer integre du GM
    chargeait des zones entieres sans compter -> au dela de 1000 le client n'affiche plus rien.
    Nouveau streamer (basicgm1.pwn, "STREAMER D'OBJETS INTEGRE v2") : grille de 60 m, objets
    tries par distance, MAXIMUM 850 objets par joueur (marge pour les objets globaux), les plus
    proches d'abord. Simule sur toutes les maps : jamais plus de 850.
    Reglages en haut du module : MS_PLAYER_CAP, MS_CELL, MS_LOAD_DIST, MS_UNLOAD_DIST.

3) MAPPINGS AVEC MODELES 3D PERSONNALISES (dossier DATA_MAPPINGS) - a activer
-----------------------------------------------------------------------------
 Sur SA-MP mobile on ne peut pas charger un modele depuis le serveur comme MTA
 (engineReplaceModel). Il faut remplacer le modele dans la DATA du jeu (IMG), sous le NOM du
 modele SA qu'il remplace. Les fichiers sont deja renommes :

  Dossier          DFF / COL (nom du modele SA)      id     TXD (nom UNIQUE, a declarer)
  BanqueAtlas      rodeo06_LAw2.dff/.col            6340   cw_atlas_alap.txd   (avant : rodeo05_law2)
  BanqueAtlas      cables3.dff/.col                 10040  cw_atlas_bank.txd
  ConcessionLS     towerlan2.dff/.col               4585   cw_dealer_ls.txd
  MecanoMTA        gzbuild2_law.dff/.col            6098   cw_mecano.txd
  ConcessionSF     carshow4_SFSe.dff/.col           11301  cw_salon_sf.txd     (avant : carshow_sfse)
  ConcessionSF     LOD_carshow4_SFSe.dff            11320  cw_salon_sf.txd

 POURQUOI des noms de TXD uniques : les TXD d'origine (rodeo05_law2, carshow_sfse...) sont
 partages par d'autres batiments. Les ecraser casserait les textures ailleurs (collision).
 Avec un nom unique il n'y a AUCUNE collision.

 Etapes :
  1. Ouvrir gta3.img (ou l'IMG de la data Crestwood) avec un editeur IMG, AJOUTER/REMPLACER les
     .dff et AJOUTER les .txd cw_*.txd.
  2. Dans les fichiers .ide de la data, chercher chaque id (6340, 10040, 4585, 6098, 11301, 11320)
     et remplacer UNIQUEMENT le 3e champ (nom du TXD) par le nom cw_*.  Exemple :
        6340, rodeo06_LAw2, rodeo05_law2, <dist>, <flags>  ->  6340, rodeo06_LAw2, cw_atlas_alap, <dist>, <flags>
     (garder les autres nombres tels quels)
  3. COL : les .col sont deja renommes en interne (nom + id du modele). Remplacer l'entree du
     meme nom dans l'archive .col qui la contient (ex. un editeur COL type "Col Editor 2").
  4. Dans server/basicgm/basicgm1.pwn mettre  #define MAP_MODELES_DATA 1  et recompiler.
     (ConcessionLS n'a besoin de rien cote serveur : il remplace directement la tour 4585.)
  ATTENTION : changer la data ET mettre MAP_MODELES_DATA 1 ensemble. Data changee avec 0 =
  batiments au mauvais endroit ; 1 sans data = batiments d'origine.
  Les 2 versions compilent (verifie). Si tu m'envoies tes fichiers .ide / .img de la data, je fais
  l'etape 2 moi-meme.

 Non repris : RC Bandit et PC du cyber (remplacent des vehicules/objets utilises ailleurs),
 accessoires du braquage Atlas (jammer, laptop, perceuse, porte : script MTA non fourni).
